\section{Extensión a PDEs y configuración numérica}
Se resolvió el sistema de reacción--difusión con elementos finitos (FEniCSx). Condiciones iniciales aleatorias se acotan en
\[
0.8 < c < 1.2, \quad 0.2 < s < 0.6, \quad 0 < i < 0.2.
\]
Parámetros de integración en los escenarios principales del repositorio: tiempo final $T\in\{1,2\}$, paso temporal $\Delta t=10^{-3}$ (artículo derivado) o $\Delta t=5\times10^{-3}$ (corridas tempranas de la tesis), malla uniforme $100\times100$ sobre dominio $[0,8]^2$ (artículo) o $[0,4]^2$ (algunas corridas de la tesis). Las ecuaciones \eqref{eqn:cancer_dynamic_spatial}--\eqref{eqn:inmune_dynamic_spatial} se resolvieron para $\mu\in\{0,1\}$. Las variables son densidades adimensionales; si una unidad del modelo corresponde ilustrativamente a $\sim100\,\mu\mathrm{m}$, entonces $L_{\mathrm{modelo}}=8$ representa una ventana de $\sim800\,\mu\mathrm{m}$, comparable a un campo histológico. Esta asignación es ilustrativa y requiere calibración experimental para fijar la escala absoluta.

\section{Síntesis}
El efecto Allee débil permite patrones amplios; $\mu=1$ aumenta coherencia y facilita contención parcial. En el efecto fuerte, la barrera crítica limita el tamaño de dominios tumorales y atenúa el impacto de $\mu$, aunque sigue actuando como organizador espacial secundario.
