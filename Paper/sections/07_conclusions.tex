\section{Conclusions}

\begin{itemize}
    \item Presented a nonreciprocal cancer--immune model with weak/strong Allee effects and immunological control.
    \item Mean-field scans reveal only unstable fixed points in current parameter ranges; Allee thresholds separate extinction vs proliferation.
    \item Spatial simulations show control-dependent pattern organization; adaptive $u$ should improve containment relative to binary $\mu$, and strong Allee caps domain sizes.
    \item Future work: refine parameter sweeps to seek stable attractors, optimize spatiotemporal $u(\mathbf{x},t)$, extend to longer simulations and heterogeneous geometries, and validate against experimental scales.
\end{itemize}
